# CyVR QuestDev showcase

A complete English/French static presentation of QuestDev: application logs, OVR curves, device actions, applications, mirroring settings, file batches, plugins, AI/MCP/SDK, retention settings, updates, documentation and downloads.

**Live showcase: [English](https://mrmybal.github.io/CyVR_QuestDev/) · [Français](https://mrmybal.github.io/CyVR_QuestDev/?lang=fr).**

## Build and open

From the project root, with Python 3.11+ and Node.js 22+:

```powershell
python website/build.py
python website/preview.py
```

Open **http://127.0.0.1:50870/questdev/** for English or **http://127.0.0.1:50870/questdev/?lang=fr** for French. The loopback preview serves only the generated artifact, under a project subpath. Stop it with Ctrl+C. Change the port with `--port` or the subpath with `--prefix /another-path/`.

The generated entry is `dist/website/index.html`. Copy the **whole `dist/website/` directory** to another location and open `index.html` directly; the page uses local classic JavaScript, styles, images and the complete CyDoc manual, without CDNs, package installation or a server dependency for reading. `fr.html` also prerenders French for opening without JavaScript. JavaScript enables language switching, the image viewer and console tabs. Opening an image in the viewer stays within the page.

The GitHub and download links point to the existing public QuestDev Alpha. Those destinations need a network connection; application installers are downloaded from the release.

## GitHub Pages deployment

The repository uses GitHub Actions as its Pages source. `.github/workflows/pages.yml` rebuilds the showcase after relevant changes on `main`, then uploads and deploys **only `dist/website/`**. It can also be run from **Actions → Publish QuestDev showcase → Run workflow**. A successful deployment updates the public English and French URLs above.

The build uses Python 3.13 and Node.js 22 with the frozen `.CyDocBuild` compiler dependencies, checks translation parity and local references, and resolves assets relative to the project subpath. Official Actions are pinned to commit revisions. The build job has read access to the source; only the deployment job receives Pages and OIDC write permissions. Generated files remain ignored in Git.

To inspect a deployment, open the workflow run and its **github-pages** environment link. Local preview commands below do not publish the site.

## Maintained files

| File | Purpose |
| --- | --- |
| `content.json` | Complete EN/FR copy, screenshot catalog, captions, alt text and verified optional destinations |
| `build.py` | Python showcase generator, shared CyDoc generation, English/French prerendering, local reference and translation checks |
| `main.js` | Language URLs, responsive navigation, keyboard tabs and modal image viewer |
| `styles.css` | Responsive graphite/orange appearance using the existing QuestDev branding |
| `preview.py` | Artifact-only loopback preview with static subpath support |
| `../.CyDocBuild/` | Bilingual manual inputs, pinned official CyDoc package, compiler lockfile and shared export configuration |
| `../docs/images/` | Existing public captures of the real app in demonstration mode; paths are selected by the catalog |

Generated files belong in `dist/website/` and are ignored by Git. Do not edit them. The build does not require Git metadata or access to GitHub. Override the output with `python website/build.py --output build/website-preview` when needed; only an empty directory or a previous generated showcase is accepted. Rebuild after changing the version or assets.

Styles, scripts, the logo and screenshots use content-hashed names. The HTML is regenerated with the matching references in the same build. A static host should revalidate HTML and may cache hashed assets for longer; cache invalidation of an already cached HTML file remains the host's responsibility.

## Documentation and licensing

The complete user manual is generated by **CyDoc**, in English and French. [English manual](https://mrmybal.github.io/CyVR_QuestDev/manual/Documentation.html#/en/overview) · [Manuel français](https://mrmybal.github.io/CyVR_QuestDev/manual/Documentation.html#/fr/overview).

`build.py` invokes `tools/documentation.py` and copies the **whole official `Documentation/` export unchanged** to `manual/`. The app and site therefore use identical pages, links, scripts, styles, media and notices. Contextual feature links preserve the selected locale. The former `guides/index.html` address redirects to the manual. Raw developer Markdown files are not the site's documentation reader.

The reader provides a page tree, search, translated navigation, images, bookmarks and notes. It opens directly as a local file or through a static host; its compiled data bootstrap does not need to fetch JSON. Optional links to downloads or other sites need a connection. Source builds of the app use Help/F1 to open a local contextual page. Existing published 0.9.0 binaries predate that integration.

Authoring and compiler maintenance are described in [`.CyDocBuild/README.md`](../.CyDocBuild/README.md). Keep its tooling and inputs out of the generated public site.

Application, showcase and manual content are **GPL-3.0-only**, copyright 2026 Cyberalien. The **CyDoc reader** and its marked, PrismJS and esbuild components retain their MIT notices under `manual/DocData/licenses/`. The artifact also includes `LICENSE.txt`, `COPYRIGHT.txt`, `THIRD_PARTY.md` and existing component notices. It ships no remote font or application runtime.

## Présentation locale

Depuis la racine du projet :

```powershell
python website/build.py
python website/preview.py
```

Ouvrir **http://127.0.0.1:50870/questdev/?lang=fr**. La vitrine présente les fonctions de l’application en français et en anglais. Les captures proviennent du mode démonstration de QuestDev ; les données sont simulées. Les commandes, packages et libellés réellement affichés dans les captures gardent leur langue d’origine.

La sortie complète `dist/website/` peut être déplacée puis ouverte par son fichier `index.html`, sans installation ni serveur. `fr.html` contient aussi le texte français prérendu. Le même manuel CyDoc, entièrement traduit en anglais et en français, est disponible dans `manual/Documentation.html`. Sa génération nécessite Node.js 22+, mais sa lecture reste autonome. Les liens de téléchargement pointent vers la release GitHub existante.

La [vitrine publique en français](https://mrmybal.github.io/CyVR_QuestDev/?lang=fr) est hébergée sur GitHub Pages. Le workflow `.github/workflows/pages.yml` génère et publie uniquement le dossier statique après les changements concernés sur `main`. Il peut aussi être lancé manuellement depuis **Actions → Publish QuestDev showcase**. Les commandes de prévisualisation ci-dessus restent locales.
