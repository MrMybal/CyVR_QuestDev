# CyVR QuestDev 0.6.0 — Alpha 1

Le mirroring du Quest vers le PC utilise désormais un vrai flux vidéo H.264, avec une fenêtre redimensionnable et le plein écran F11. Les réglages permettent de choisir résolution, fréquence, débit, recadrage et audio : duplication avec le casque ou sortie PC seule.

Un fichier MKV peut enregistrer simultanément le flux vidéo/audio. L’arrêt, la fermeture et le changement de casque finalisent la session. Les actions `mirror_start` / `mirror_stop` sont accessibles au SDK/MCP avec la politique d’autorisation habituelle, et leur état est exposé dans le contexte IA.

La distribution Windows inclut scrcpy et le runtime Python/Core/MCP. Extraire le ZIP entier puis lancer `CyVR_QuestDev.exe`. ADB reste à installer séparément. Le code source correspondant et les sources des dépendances de mirroring sont fournis dans l’archive Source, avec les licences.

Version **Alpha** : cadence et audio dépendent du casque, de l’application et de la liaison. La duplication audio nécessite Android 13+ ; certaines apps refusent la capture. La vidéo s’ouvre dans une fenêtre dédiée. Voir `docs/MIRRORING.md` et `docs/VALIDATION.md`.
