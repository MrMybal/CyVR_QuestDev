# CyVR QuestDev 0.6.0 — Alpha 2

Le nouveau logo CyVR QuestDev apparaît dans l’en-tête de l’interface, sur l’exécutable et comme icône de fenêtre et de barre des tâches Windows. Le PNG transparent et l’icône en dix résolutions sont fournis avec le projet ; le logo de l’interface est embarqué dans l’EXE.

Le README présente le même logo et une capture actualisée de la console. L’archive Windows conserve le moteur de mirroring vidéo/audio, les plugins et le runtime Python/Core/MCP. Extraire toute l’archive et lancer `CyVR_QuestDev.exe` ; ADB reste externe.

La connexion MCP locale est retirée dès le début de la fermeture du runtime, avant le drainage des tâches.

Version **Alpha**. Voir `docs/RELEASE.md`, `docs/MIRRORING.md` et `docs/VALIDATION.md` pour l’utilisation et les limites.
