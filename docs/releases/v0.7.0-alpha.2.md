# CyVR QuestDev 0.7.0 — Alpha 2

Un installateur **Windows x64** est maintenant proposé : `CyVR_QuestDev-0.7.0-alpha.2-Windows-x64-Setup.exe`.

L’assistant français/anglais installe l’app pour le compte Windows courant, sans droits administrateur, avec son logo, un raccourci dans le menu Démarrer et un raccourci Bureau facultatif. Une entrée de désinstallation est ajoutée dans les applications Windows.

Les mises à jour depuis **Réglages → Mises à jour GitHub** restent disponibles après installation. Les raccourcis et la désinstallation sont conservés. Désinstaller retire les fichiers de l’app, y compris ceux ajoutés par de nouvelles versions, et conserve les préférences, sauvegardes et fichiers personnels.

Le ZIP portable et le code source correspondant restent disponibles. Le runtime Python, CyToolsCore/MCP, les plugins et scrcpy sont inclus ; ADB et les CLI des fournisseurs IA restent externes. Le Setup n’est pas signé avec un certificat de signature de code Cyberalien. Voir `docs/INSTALLATION.md` et `docs/VALIDATION.md`.
