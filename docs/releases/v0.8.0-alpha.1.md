# CyVR QuestDev 0.8.0 — Alpha 1

- **Applications** : compteurs par catégorie et nombre de résultats après recherche.
- **Logs** : limites de lignes et de mémoire configurables et sauvegardées dans **Réglages → Limites du journal**. Préréglages Standard, Étendu et Longue session ; accès rapide en cliquant les compteurs du bas.
- **Device Actions** : icônes sur les cartes et interrupteurs animés pour GPU, HUD/CSV, Wi-Fi ADB, proximité et Boundary. Les états inconnus et commandes non vérifiées sont indiqués.
- **Fichiers** : mode PC / Quest côte à côte, sélection multiple et liste de transferts optionnelle. Préparer les lignes, lancer le lot séquentiel, annuler un fichier ou tout le lot, reprendre après une erreur. Les destinations sont liées à leur casque et les remplacements sont désactivés par défaut.
- Isolation des handles des processus ADB pour éviter qu’une capture parallèle garde des fichiers temporaires verrouillés.

L’installateur Windows x64, le ZIP portable, les sources correspondantes et `SHA256SUMS.txt` sont disponibles. Les versions 0.7+ peuvent utiliser **Réglages → Mises à jour GitHub**, canal Alpha. Terminer ou annuler les listes de transferts avant un redémarrage de mise à jour.

Le runtime Python, CyToolsCore/MCP, les plugins et scrcpy sont inclus. ADB et les CLI des fournisseurs IA restent externes. Le Setup n’est pas signé avec un certificat de signature de code Cyberalien. Version Alpha : voir `docs/FILES.md` et `docs/VALIDATION.md`.
