# CyVR QuestDev 0.9.0-alpha.1

[English](v0.9.0-alpha.1.md) · [Français](v0.9.0-alpha.1.fr.md) · [README](../../README.fr.md)

**Statut : Alpha. Version disponible : Windows 10/11 x64.** Cette release est destinée aux essais et aux retours ; certaines fonctions dépendent encore d’applications externes et du firmware du casque.

## Changements de cette version

- Intégration modulaire de CyUI 1.2.0 épinglé à `ff023e646c6a3038b3dfbfd53f6d2b4a2f5955e3`, avec une seule instance de Dear ImGui et uniquement les modules nécessaires.
- Rendu commun des courbes OVR, axes, zoom et déplacement. QuestDev conserve les CSV, l’enregistrement, les statistiques, le curseur temporel commun et la préservation des pics/valeurs manquantes.
- Vues RAW Logcat, sortie ADB et JSON de plugin sélectionnables en lecture seule via CodeEditor, avec copie et politique de suivi du direct conservée.
- Discussion Markdown avec tableaux, blocs de code, mises à jour progressives et identifiants de messages stables via DocumentViews.
- Aperçu des captures avec zoom, déplacement et ajustement via Images.
- Préférences EN/FR et densité sauvegardées pour les vues migrées, avec thèmes et DPI. La traduction reste partielle.
- Sources CyUI correspondantes complètes et notices supplémentaires TextEditor/Lexilla/Scintilla/SciTE dans la distribution des sources.

## Téléchargements et mise à jour

L’[Alpha publiée](https://github.com/MrMybal/CyVR_QuestDev/releases/tag/v0.9.0-alpha.1) fournit un installateur Windows x64, un ZIP portable, le ZIP Source correspondant et `SHA256SUMS.txt`. L’installateur n’est pas signé. Python 3.13.17, CyToolsCore/MCP, les plugins et scrcpy sont embarqués ; ADB, les CLI/comptes IA et les applications Quest restent externes.

Dans une distribution installée ou portable, choisir **Réglages → Mises à jour GitHub → Alpha et préversions**. Les copies de développement utilisent la compilation depuis les sources. Consulter les guides d’[installation](../INSTALLATION.md) et de [mise à jour](../UPDATES.md).

## Limites connues

- Le programme natif repose sur Win32/DirectX 11. Aucune application Linux ou macOS n’est fournie.
- Les journaux commencent au présent de la capture. Des messages peuvent manquer pendant une interruption ; les origines inconnues restent système/non attribuées. Le RAW est paginé à 10 000 lignes ou 2 Mio ; la copie/export de toute la vue filtrée est distincte.
- Les tableaux de logs Android et de fichiers PC/Quest restent propres à QuestDev : les modules communs ne couvrent pas leurs règles d’attribution, colonnes et transferts. Consulter le [guide des modules](../CYUI_MIGRATION.md).
- L’enregistrement OVR nécessite OVR Metrics Tool et une application VR en cours d’exécution. Les compteurs et la cadence d’écriture CSV dépendent d’OVR/du firmware. Aucun test matériel Quest supplémentaire n’a été réalisé pour la migration UI.
- Les transferts concernent les fichiers réguliers. Copie de dossiers, suppression récursive, accès root et bundles APK ne sont pas implémentés. Les listes de transferts préparées durent le temps de la session courante.
- Le mirroring utilise une fenêtre scrcpy dédiée. L’audio nécessite Android 13+ et peut être indisponible selon l’app. La vidéo Android MP4 reste limitée à 180 secondes et les captures Perfetto à 120 secondes.
- Seul le profil Codex intégré appelle actuellement les outils natifs QuestDev. Les autres fournisseurs intégrés proposent du texte contextualisé ; les clients MCP externes compatibles accèdent au catalogue d’outils.
- Le rendu Markdown natif couvre un sous-ensemble du format, sans HTML/scripts. Cette Alpha n’assure pas une parité complète avec MQDH.
