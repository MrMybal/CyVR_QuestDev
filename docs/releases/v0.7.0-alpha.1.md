# CyVR QuestDev 0.7.0 — Alpha 1

La page **Réglages → Mises à jour GitHub** recherche les nouvelles versions, affiche leurs notes et permet de télécharger puis installer une mise à jour avec redémarrage. Les canaux stable et Alpha/préversions sont disponibles ; la recherche au démarrage est facultative.

L’accès au dépôt privé réutilise la connexion Git existante ou un jeton enregistré dans le Gestionnaire d’identifiants Windows. Le ZIP et ses fichiers sont vérifiés avant la préparation. L’ancienne installation est sauvegardée ; un échec du nouveau démarrage déclenche sa restauration. Les préférences utilisateur et les fichiers personnels supplémentaires sont conservés. Une restauration manuelle est aussi accessible dans la page des mises à jour.

Cette première version avec updater doit être téléchargée et extraite manuellement depuis une ancienne Alpha. Les mises à jour suivantes pourront être installées depuis cette page. Utiliser un dossier portable dédié et modifiable, puis arrêter les enregistrements et le mirroring avant l’installation.

Les fonctionnalités de mirroring, métriques, plugins, fichiers, console et assistant IA restent disponibles. Version **Alpha** : voir `docs/UPDATES.md`, `docs/RELEASE.md` et `docs/VALIDATION.md`.
