# CyVR QuestDev 0.9.0-alpha.1

[English](v0.9.0-alpha.1.md) · [Français](v0.9.0-alpha.1.fr.md) · [README](../../README.md)

**Stage: Alpha. Available build: Windows 10/11 x64.** This release is intended for testing and feedback; some features remain dependent on external applications and headset firmware.

## Changes in this release

- Modular CyUI 1.2.0 integration pinned to `ff023e646c6a3038b3dfbfd53f6d2b4a2f5955e3`, with one Dear ImGui instance and only the required modules.
- Shared OVR chart rendering, axes, zoom and pan. QuestDev retains CSV handling, recording, statistics, the shared time cursor and missing-sample/peak preservation.
- Selectable read-only RAW Logcat, ADB output and plugin JSON views through CodeEditor, with clipboard support and the existing live-follow policy.
- Markdown conversations with tables, code blocks, streaming updates and stable message identities through DocumentViews.
- Screenshot preview with zoom, pan and fit through Images.
- Saved EN/FR language and density preferences for the migrated interface, with theme and DPI support. Translation remains partial.
- Complete corresponding CyUI sources and additional TextEditor/Lexilla/Scintilla/SciTE notices in the source distribution.

## Downloads and updating

The [published Alpha](https://github.com/MrMybal/CyVR_QuestDev/releases/tag/v0.9.0-alpha.1) provides a Windows x64 installer, portable ZIP, matching Source ZIP and `SHA256SUMS.txt`. The installer is unsigned. Python 3.13.17, CyToolsCore/MCP, plugins and scrcpy are bundled; ADB, AI provider CLIs/accounts and Quest-side apps remain external.

For an installed or portable distribution, choose **Settings → GitHub updates → Alpha and prereleases**. Developer checkouts use the source build workflow. See the [installation](../INSTALLATION.md) and [update](../UPDATES.md) guides in French.

## Known limitations

- The native host is Win32/DirectX 11. No Linux or macOS application build is provided.
- Logs start at the current capture time. Messages from interruptions may be missing; unknown origins remain system/unassigned. RAW is paginated at 10,000 lines or 2 MiB; full filtered copy/export is separate.
- The Android-specific column log view and PC/Quest file tables remain in QuestDev because the common modules do not cover their attribution, columns and transfer rules. See the [module guide](../CYUI_MIGRATION.md).
- OVR recording requires OVR Metrics Tool and a running VR application. Available counters and CSV write cadence depend on OVR/firmware. No extra Quest hardware validation was performed for the UI migration.
- File transfers cover regular files. Folder copying, recursive deletion, root access and APK bundles are not implemented. Prepared transfer lists last for the current app session.
- Mirroring uses a dedicated scrcpy window. Audio requires Android 13+ and may be unavailable in some apps. Android MP4 recording remains limited to 180 seconds; Perfetto captures to 120 seconds.
- Only the integrated Codex profile currently calls native QuestDev tools. Other integrated providers offer text with context; compatible external MCP clients can use the tool catalogue.
- The native Markdown renderer supports a subset of Markdown, without HTML/scripts. This Alpha does not provide full MQDH feature parity.

## Bugs and feedback

The published release notes do not provide a bug-by-bug issue list. The limitations above are not a list of confirmed bug tickets. Use the [issue tracker](https://github.com/MrMybal/CyVR_QuestDev/issues) to report reproducible problems, including the QuestDev version, headset/firmware and relevant steps.
